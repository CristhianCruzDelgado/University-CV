Introduction to modern CMake for beginners
https://www.internalpointers.com/post/modern-cmake-beginner-introduction

Following the tutorial above, the files have been adapted to
carry out the tutorial with the program "fibonacci_sum.cc", which computes
the sum of the even terms of the Fibonacci sequence.

The code generated from tools.cc is placed in a library, to
illustrate that process (creating a user-defined library).

If you are going to follow the tutorial, first make a copy of the CMakeLists.txt file in this directory
